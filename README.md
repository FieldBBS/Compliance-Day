# 🎯 Quiz Compliance - Caça às Red Flags

Aplicação web desenvolvida em HTML, CSS e JavaScript para treinamento gamificado de Compliance, identificação de Red Flags e conscientização sobre riscos corporativos.

## 🚀 Funcionalidades

- Quiz interativo
- Perguntas embaralhadas
- Sistema de pontuação
- Classificação por desempenho
- Ranking local utilizando LocalStorage
- Interface responsiva
- Efeitos visuais e animações

## 📊 Pontuação

- ✅ Acerto de Red Flag: +10 pontos
- ✅ Acerto de Risco: +20 pontos
- ❌ Erro: 0 pontos

## 🏆 Classificações

| Pontos | Classificação |
|----------|----------|
| 120 a 150 | 🥇 Guardião do Compliance |
| 90 a 119 | 🥈 Radar de Riscos |
| 60 a 89 | 🥉 Olhar Atento |
| 30 a 59 | 📘 Em Desenvolvimento |
| Abaixo de 30 | ⚠️ Atenção |
